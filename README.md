숫자 야구 게임 만들기

먼저 메인을 실행하면 BaseballGameDisplay 가 display 라는 객체로 생성되게 만들었습니다.

displayhint 라는 메소드가 작동하면 안내 문구가 나오게 되고

원하는 번호를 입력하도록 하였습니다.

0번을 입력하면 자리수를 이용하여 난이도를 설정하게 만들었고 바로 게임이 시작되도록 하였습니다.

1번을 입력하면 설정되어 있는 난이도로 게임이 시작되도록 하였습니다.

2번을 입력하면 지금까지 진행한 게임 횟수와 해당 게임에서 정답을 맞추기까지 시도한 횟수를 확인할 수 있습니다.

3번을 입력하면 안내 문구와 함께 프로그램이 종료되도록 만들었습니다.

난이도를 설정할 시 3,4,5 만 입력할 수 있으며 나머지는 예외처리를 하였습니다.

게임을 진행 할때에는 3자리 숫자만 입력할 수 있으며 0은 입력할 수 없고 나머지는 예외 처리 되도록 하였습니다.
